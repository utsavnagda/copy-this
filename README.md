# copy-this

Free prompts and skills you paste into Claude, ChatGPT/Codex or Grok.

## How to use
1. Open a prompt in `prompts/`.
2. Paste the raw file link (or the whole text) into your AI chat.
3. The AI reads it and runs it with you.

Try it: paste this into your AI.

```
Read https://raw.githubusercontent.com/utsavnagda/copy-this/main/prompts/outbound-autopsy.md and run it with me.
```

## Prompts
- `prompts/outbound-autopsy.md`: find which of five checks is breaking your cold outreach (about 16 questions).
  Built on Eric Nowoslawski's method for diagnosing a failed cold email campaign.
